Projects That Define Me

01
Backend · Distributed SystemsIn active development

Stampede

A ticketing platform built for the worst five minutes in ticketing: thousands of buyers racing for the same seats. Seat holds run through pluggable locking strategies that are load-tested head to head, every test run is checked against invariants like “no seat is ever sold twice”, and tickets are Ed25519-signed so they can be verified offline. Every architecture choice is written up with its trade-offs.
